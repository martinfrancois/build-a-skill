# Agent Instructions

Skill Starter is a template repository for one Agent Skill, `my-skill`, with Tessl evals that
measure whether the skill changes what an AI coding agent writes.

Before starting any task, open [Workflow](docs/agents/workflow.md) and follow it.

When the user corrects wording, naming, scope, eval design, or project policy, make that
correction durable in the relevant file under `docs/agents/`.
