# Maintaining Agent Docs

- Keep root `AGENTS.md` limited to repository identity, the entry point, and links.
- Put topic-specific detail in one owning page under `docs/agents/`; the template's own pages
  own the rules of the repositories it produces.
- When the user states a preference or corrects a repeatable mistake, update the owning page in
  the same change.
- Remove vague, duplicated, or obsolete prose.
